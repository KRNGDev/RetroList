# RetroList

## Descripción

**RetroList** es una aplicación diseñada para integrar con la API de **RetroAchievements**, proporcionando una plataforma para crear una red social enfocada en juegos retro. Esta app permite a los usuarios gestionar sus logros, interactuar con otros jugadores y compartir su pasión por los videojuegos clásicos.

## Características

- **Gestión de logros**: Consulta y organiza tus logros obtenidos en juegos retro.
- **Perfil de usuario**: Los usuarios pueden crear perfiles personalizados para mostrar sus logros y estadísticas.
- **Interacción social**: Comenta, comparte y compite con otros entusiastas de los juegos retro.
- **Integración con la API de RetroAchievements**: Accede a datos en tiempo real, como logros y clasificaciones.
- **Exploración de juegos retro**: Navega por un catálogo de títulos retro y sus logros asociados.

## Tecnologías Utilizadas

- **Frontend**: Angular, Ionic
- **Backend**: Node.js
- **Lenguaje de Programación**: TypeScript
- **Estilos**: SCSS
- **API**: RetroAchievements
